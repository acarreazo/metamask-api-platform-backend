# MetaMask API Platform – Backend (WIP)

This repository is an early-stage backend project intended to explore and demonstrate 
API platform engineering concepts using Node.js and TypeScript.

The goal of this project is to build a production-oriented backend service with
clear structure, documented decisions, and incremental evolution.

## How to run (API)

Prerequisites:
- Node.js 20+

Steps:
1) cd apps/api
2) npm install
3) npm run dev

Health check:
- http://localhost:3000/health
- Expected response: { "status": "ok" }
